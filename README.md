# Projet AlgoBox Binôme

Ce projet contient des algorithmes pour calculer l'IMC et photocopie.
Réalisé par **[Bigot Louis]** et **[Mohamed Karim]**.

## 📂 Structure du projet
- `src/` : Contient tous les fichiers sources (.algo).

## 🚀 Comment l'utiliser
1. Installez le logiciel [AlgoBox](https://www.xm1math.net/algobox/).
2. Lancez AlgoBox.
3. Cliquez sur **Fichier > Ouvrir**.
4. Naviguez dans le dossier `src` et sélectionnez l'algorithme souhaité.
5. Cliquez sur le bouton **TESTER L'ALGORITHME**.
